MaizeGuard: Task-Aware Inference System Optimization [GitHub]

  • Built a CPU/CUDA dual-ONNX system for multi-ear maize anomaly analysis, including an application-level runtime prototype with bounded in-flight tasks, CPU workers, and a device execution thread to overlap pipeline stages.

Multi-Agent Coordination with Reinforcement Learning and Local Planning

Individual Summer Research Project, Zhejiang University · Supervisor: Prof. Fei Miao

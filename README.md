# You Zhang's Academic Homepage

This repository hosts the academic homepage at <https://iyoyovo.github.io/>.

## Updating the website

- Edit `index.html` to update the English or Chinese content.
- Edit `styles.css` to change typography, spacing, colors, or layout.
- Replace `profile.png` to update the portrait.
- Replace `cv_youzhang.pdf` to update the downloadable CV while keeping the existing link.
- Commit and push changes to the `main` branch. GitHub Pages will publish the new version automatically.

The site is intentionally dependency-free and can be previewed by opening `index.html` or serving this directory with a simple local HTTP server.
